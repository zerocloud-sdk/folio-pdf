# Use a permissively licensed clean-room implementation

The project will be an independently implemented alternative under the Apache License 2.0 rather than an AGPL-derived implementation or a reuse of commercially licensed iText components. The initial intended implementers report no exposure to iText source and no reverse engineering of closed add-ons; legal review is available. iText source code and resources will not be copied or adapted, and closed add-ons will not be reverse-engineered. Implementations will be based on standards, public API documentation, project-owned fixtures, and legally approved black-box differential evidence, with standards remaining the authority for correctness and every contributor required to record provenance. Only a Compatibility Curator separate from the corresponding implementers may produce approved closed-product comparisons; that role is currently vacant, so such evidence and dependent closed-product claims remain unavailable until the role is staffed. Core runtime dependencies must use compatible permissive licenses; integrations with reciprocal or commercial dependencies must remain optional and isolated.
