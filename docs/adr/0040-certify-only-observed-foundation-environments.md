# Certify only observed Foundation environments

For Foundation `0.1.0` only, the maintainer's [2026-09-08 amendment in #69](https://github.com/zerocloud-sdk/folio-pdf/issues/69) supersedes the four-platform requirement in [ADR-0026](0026-certify-foundation-typography-on-four-platform-targets.md): required certification covers the actual Ubuntu 24.04 / Linux x86-64 environments exercised with JDK 8, 11, 17 and 21, with exact JDK vendor/build, immutable OS image, execution configuration, native engine and tool identities bound to the tested candidate. Windows x86-64 and macOS x86-64/arm64 remain explicitly uncertified and are not required release gates for this version; a shared architecture, floating image tag, installation receipt or passing local test does not extend certification to another environment.

All other [#1](https://github.com/zerocloud-sdk/folio-pdf/issues/1) and [#33](https://github.com/zerocloud-sdk/folio-pdf/issues/33) requirements, including the full Foundation Composition Profile, independent evidence, hash-pinned reference fonts, matching Stable Migration Facade and non-goals, remain in force. Independently evidenced password scopes and table phases retain their aggregate obligations and inherited technical dependencies; project-specific controls may be Native Interface only with a recorded reason, while missing required behavior or migration mappings remain release blockers.
