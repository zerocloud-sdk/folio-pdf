# Use Folio PDF as the public name

The public name is Folio PDF. LibrePDF already publishes the established OpenPDF Java library, so public discovery and migration material uses “Folio PDF by ZeroCloud” and prominently disclaims affiliation with LibrePDF OpenPDF and Apryse iText; Java packages and Maven coordinates remain brand-neutral. Name and legal review are advisory rather than a release gate. A credible naming dispute triggers reconsideration of this ADR even though review is not a release prerequisite.
