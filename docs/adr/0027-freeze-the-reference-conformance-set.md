# Freeze the Reference Conformance Set

Conformance parity is limited to the iText 7.2.6 baseline: PDF/A-1A/1B, PDF/A-2A/2B/2U, PDF/A-3A/3B/3U, plus tagged and metadata-assisted PDF/UA-1 creation without an asserted public PDF/UA validator. PDF/A-4, PDF/UA-2, and the later standalone `pdfua` module are version-crossing features and remain outside the Reference Suite; independent acceptance validation stays stricter than in-process Creation Checks without being misrepresented as a reference public interface.
