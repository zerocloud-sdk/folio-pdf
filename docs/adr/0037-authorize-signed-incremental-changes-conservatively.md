# Authorize signed incremental changes conservatively

Folio PDF recognizes Existing Signatures without claiming to validate their cryptography, preserves every prior revision through `INCREMENTAL` publication, and computes Signature Permission as the intersection of all applicable restrictions. Version 1 denies signed `REWRITE`, ordinary-signature mutation, DocMDP P=1 mutation, and all current P=2 commands; it admits only the non-form annotation changes represented by `UpdateAnnotations` under an unambiguous sole DocMDP P=3 certification policy. This is narrower than every operation PDF permits because missing or unsupported permission evidence must not silently become mutation authority, and Forms, template instantiation, signing, and cryptographic validation belong to downstream capabilities.
