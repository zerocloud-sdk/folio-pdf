# Use Open PDF as the public name

The public name is Open PDF even though LibrePDF already publishes the established OpenPDF Java library. Name and legal review are advisory rather than a release gate, so the project knowingly accepts ecosystem and brand-confusion risk. Public discovery and migration material uses “Open PDF by ZeroCloud” and prominently disclaims affiliation with LibrePDF OpenPDF and Apryse iText; Java packages and Maven coordinates remain brand-neutral. A credible naming dispute triggers reconsideration of this ADR even though review is not a release prerequisite.
