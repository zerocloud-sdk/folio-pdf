# T78 independent security checker supplement

`t78-r1.patch` applies to Apache-2.0 pdfcpu v0.15.0, commit
`f2686555086a2e76dc19f602ea1897f6e3baae4d`. Original copyrights remain with
the upstream authors. The added lines were authored for Folio under Apache-2.0.
This is an acceptance installation; it is never a product dependency.

ISO 32000-1:2008 Table 25 makes Standard-handler crypt-filter `Length` optional
and expresses it in bytes. The supplement fixes two upstream branches that
require it and interpret AESV2/V2 lengths as bits. A present non-integer still
fails. Public-key handling and the original signed 32-bit permission validator
are unchanged. Public source and clause links are in
`docs/research/T78-baseline-profile-audit.md`.

The separate `pdfcpu-t78-r1` identity does not replace the original pdfcpu
installation. The original checker remains the core-document checker on private
decrypted derivatives. The supplemented checker validates the original encrypted
bytes. Arlington checks the separately frozen dictionary predicates, and pypdf
checks authentication and all fixed `Perms` bytes. No single check establishes
full ISO conformance.

Run `python3 scripts/provision-t78-pdfcpu.py` to verify the source archive, apply
this patch without fuzz, use Go 1.25.0 and its checksum-verified modules, and
compare the resulting executable to `scripts/t78-pdfcpu-pin.properties`. Build
metadata fixes the tool version, source commit and date. Source tests and
testdata are not consulted or used as Folio fixtures. All qualification fixtures
are original and generated by `scripts/generate-t78-controls.py`.
