# Foundation extraction collector development

These records cover the public `t03-foundation.py collect --obligation text`
boundary. Its synthetic fixtures describe the recorder protocol and exercise
rejection behavior; they are not PDF or independent-tool qualification evidence.

The first implementation collects the original complete artifact receipt,
ten Native/Facade products with their actual modes, six required visual products,
successful Publication Receipts and complete detached/reopened public values.
It validates the exact 334 declaration rules, frozen profiles and tools, and
the original controls. Missing-route, publication, declaration and retained-file
RED/GREEN records preserve the development sequence.

The first independent reviews found two P1 issues: late file hashes could replace
producer digests during export, and declaration completion/exit states were not
checked. The late-file public CLI test changes the test-owned generation receipt
after the original run manifest has been read; its initial RED accepted the
changed bytes. The collector now retains an index of the original hashes, parses
only bytes that match those hashes, exports those same identities and verifies
the tree again before returning. Five public tests passed in 64.477 seconds,
including the changed-receipt regression. The index also removes repeated
whole-tree filtering; the preceding four-test run took 191.246 seconds.

The declaration process-state RED retains a detected finding but changes the
recorded exit to 137; the original collector incorrectly accepted it. Positive
completion/version/exit envelopes and the qualified negative exits are now
checked; all six public tests passed in 84.966 seconds.

The actual 19,700-file recorder tree then exposed a protocol-fixture mismatch:
the whole-run producer owns observation.properties, reopened.properties and
publication.properties, while the combined chain owns its separate subtree
receipt. The corrected collector verifies those three exact files through the
parent receipt and the public outcome checks. Six public tests passed in 83.988
seconds, and the actual corpus export passed with 10/10/10/6 products. The
retained export preserves its original local paths; the corresponding bytes
are archived under recorder-r5, not claimed as a current certification index.

The public unverified plan now exposes the common tool catalog, including
Arlington T13 and the T13 semantic producer; 29 Foundation compatibility tests
passed. An old exact catalog expectation was extended by the newly required
T13 entry, with its original failure retained.

The second independent reviews closed both P1 findings and verified all 26,473
exported references against the actual 19,700 original files. Standards found
one P2: a root manifest could name its own report or manifest, and the index
silently overwrote that conflicting identity. An actual public CLI RED accepted
the conflict; the collector now rejects both reserved names before indexing.
The focused two-test GREEN and independent read-only closure are retained in
`r2-closure-archive-identities.json`. No reviewer reran the CLI or mutation probes.

The next vertical slices verify the detailed syntax, semantic, program and
visual reports. Each retains its public CLI RED before the minimal GREEN.
Program collection checks all eight scopes, 42 rules and 165 original controls;
semantic collection checks the ten-file producer receipt and detached values.
Real recorder collection exposed decimal ImageMagick AE (`86.9647`) alongside
the distinct exact changed-pixel count (`672`); both now retain their original
independent bounds. The visual decimal regression passed in 79.309 seconds,
and real collection passed with 10/10/10/6 products. Standards exports include
18,252 original control references, including program qualification artifacts.

The four-chain independent reviews found one P1 each: authority files could be
parsed from a later read than their checked digest, and visual tool summaries
were not compared with raw stdout. A public CLI RED accepted a qpdf pin changed
after its last observation. Authorities now use one captured byte snapshot and
are rechecked before export; that test passed in 19.841 seconds. The stdout RED
accepted an unqualified PDFium version while the summary retained its pinned
label; the corrected version/render-output checks passed in 50.163 seconds.
These findings and the frozen review are retained under
`four-chains-review-archive-identities.json`; the later closure is recorded below.

Truncated syntax and invalid Catalog controls passed their focused regression

Complete visual negative-batch collection passed in 70.412 seconds, including
