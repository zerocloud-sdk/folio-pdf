# Declaration standards aggregation qualification

The public declaration command executes seven pinned profiles and requires their
exact 334-rule union. Original RED/GREEN records cover the absent command, altered
whole pins with genuine tools, and tool/pin changes after a group has finished.
The initial 19-test regression passed with all independent tools actually run.

Both independent review axes found that retained files could change after their
observations without invalidating PASS. All five reproduced variants returned
PASS/334, including a report changed before its own group finished. Producer-time
digests now bind copied control bytes and actual process outputs; the aggregate
rechecks those receipts and exports a digest manifest. The initial closure
regression passed 17 tests with no skips. Subsequent independent review found a
separate final-publication link boundary. Three actual RED variants followed
preplanted links for the summary, manifest and final result, modified unrelated
test-owned files and still passed. CREATE_NEW publication and ancestor link
checks now reject all three. The first attempted GREEN exposed an exception
instead of the existing INDETERMINATE result for a missing retained control;
that regression is preserved and corrected. Final focused validation passes
18 tests with no skips.

Both axes independently closed the final publication finding. Standards ran
seven actual CLI controls and Spec ran five; genuine observations still pass
334 rules, missing retained controls return INDETERMINATE/0, and final links
are refused without changing their external targets. Standards also observed
refusal to overwrite a regular final record. Its deliberately non-properties
marker caused the review harness parser to fail after the CLI correctly refused;
the original output and recovery assessment disclose that harness event.
The first and final closure source catalogs select additional archives using
the same retention recipe, with separate identity manifests. Full candidate
certification and the final clean-context review gate remain outstanding.

The later program-recorder closure extended the shared writer's ancestor check
to the complete filesystem path and removed a Java fallback directory creation.
`shared-helper-closure-archive-identities.json` retains the full passing
declaration observation, the shared-publication controls, all three final-file
link controls, and the two frozen shared-helper snapshots. The corresponding
24-test full regression and 17-test final focused regression logs are retained
in `recorder-r4`; both executed all selected tests without skips. The final
incremental reviews and their read-only closure method are described there.

`retain-declarations.py` records every original member identity and verifies each
archived file by reading it back and comparing its exact bytes. Absolute symlinks
are listed as identities instead of being installed on extraction. Compiled
classes/dependency resources and external ELF binaries are identified but excluded
from the archives. The pdfcpu binaries used by local identity controls are
reconstructible from the pinned original, with any appended zero byte recorded
and byte-verified. Original task directories remain intact. These records are
incremental qualification, not final candidate certification or a completion gate.
