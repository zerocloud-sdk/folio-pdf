# T21 fixed boundary coverage

The [coverage authority](coverage.json) and [mandatory named cases](mandatory-tests.txt)
freeze certification before observation. The profile requires the actual
HARDENED_WORKER Native Interface on all four declared Ubuntu/JDK tuples. Shared
public contracts also execute IN_PROCESS; the existing Migration Facade executes
IN_PROCESS. Each tuple retains syntax, standards, semantic, visual and contract
records, all original bytes and a fresh reproduction.

The exact named-case authority is checked against runner declarations and actual
starts/finishes; an aggregate count is insufficient. The 137 required cases must
have zero failures, ignored tests, assumption skips or duplicate executions.
The Linux image, JDK build, absolute Java/prlimit and all tool identities are
observed, rather than inferred from a passing summary.

The normative [certification contract](../../../docs/t21-certification.md)
defines producer qualifications, replay normalization, prerequisites, scope,
required gates and predecessor refresh order. No acceptance class enters the
production Worker. This profile does not certify #83 recovery/scale, Windows,
macOS, full RSS/native allocation, kernel/container isolation or physical erasure.
